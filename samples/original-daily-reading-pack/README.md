# Rivermark Reading Practice

This is a fully original, public engineering sample for IELTS Workbench. It is not an official IELTS paper and contains no Cambridge content.

- Reading module schema: v3; pack manifest schema: v1.
- Three passages and forty stable question objects numbered 1–40.
- Covers TFNG, YNNG, single choice, explicit multiple choice, four matching modes, short answer, fill blank, table input, summary input, and notes input.
- Every question, group, section, option, content block, and structured-context node has a stable ID.
- Correct answers are included so submission, Review, history, and retry can be tested without private material.

Desktop import: open **Import Center → IELTSPack v1 folder**, choose this folder, review the native validation report, confirm the rights checkbox, and install. The source folder remains unchanged.

The matching original text-layer PDF is generated by `../original-daily-reading-pdf/scripts/generate_original_daily_reading_pdf.py` into the Git-ignored `local-data/import-samples` directory. That PDF is intended to exercise the human-confirmed PDF workflow; importing it does not automatically recreate the checked-in pack.
