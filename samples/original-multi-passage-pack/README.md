# Northbridge Field Notes

This is an original, reading-only `IELTSPack v1` acceptance sample written for IELTS Workbench.

- It contains three passages and Questions 1–21.
- Question 18 belongs to Passage 3.
- Question 14–20 crosses the Passage 2/3 boundary.
- Passages 1 and 3 deliberately repeat the sentence “A small brass marker was fixed beside the entrance.” under different stable block IDs, so annotation isolation can be verified.
- It uses only the question types already supported by the application.

In the desktop app, open **Import Center → IELTSPack v1 文件夹 → 选择题包目录**, choose this folder, review the validation report, confirm the rights checkbox, and install it. The source folder remains unchanged.
