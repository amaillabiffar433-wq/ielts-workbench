# Changelog

All notable changes to IELTS Workbench are documented here.

## 0.1.0 - 2026-09-14

### Features

- Added a Windows-first, local-first IELTS Academic desktop workbench for Listening, Reading and Writing.
- Added Tauri 2 + Rust workspace boundaries, SQLite persistence, backups and recovery flows.
- Added original `IELTSPack v1` demo materials and safe JSON folder import.
- Added Reading PDF import assistance, structured passage/table/list context, dual-pane practice and local visual/OCR support.
- Added draft autosave, manual versions, review, settings and disabled-by-default AI provider boundaries.

### Project status

- The repository includes recorded TypeScript, Rust, renderer and native acceptance evidence.
- Cambridge IELTS books, answer keys, audio, scans and transcripts are intentionally excluded.
