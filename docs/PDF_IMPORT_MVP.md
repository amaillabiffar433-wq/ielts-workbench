# Reading PDF 辅助导入 MVP

## 范围与边界

本功能把用户合法持有的、本机 PDF 半自动整理为现有 `IELTSPack v1` Reading 题包。它不是批量抓取器，也不承诺自动还原整本试题；当前不联网、不上传 PDF、不调用 AI、不执行 OCR。

PDF 内容仍由用户负责合法取得和使用。真实 IELTS/Cambridge 材料、提取文本、答案、解析缓存和本地数据库都不得进入 Git。

## 从百度网盘准备文件

1. 在百度网盘客户端或网页中找到用户本人有权使用的 PDF。
2. 只下载少量副本到 `local-data/import-samples/`；不要移动、改名或删除网盘原文件。
3. 不要把网盘 token、分享口令或绝对源路径写入项目。

本次 Codex 环境暴露的百度网盘连接器实际只有上传能力，没有搜索、列表或下载命令。因此本轮没有读取或下载任何网盘文件，也没有上传、移动、重命名或删除网盘内容。实现与自动化测试使用原创材料；待连接器提供只读能力后再做真实私有样本验收。

`local-data/`、`*.pdf`、解析临时目录和数据库文件均被 `.gitignore` 排除。导入前仍应运行 `git check-ignore` 复核。

## 使用步骤

1. 在 Import Center 选择“导入 Reading PDF”，或直接进入 `#/import/pdf`。
2. 通过文件选择器或拖放载入本地 PDF。页面显示文件名、大小、页数和 SHA-256；超过 50 MB 会警告。
3. 使用上一页/下一页按需预览单页画布和该页文本层，不会一次渲染整本文件。
4. 填写 Passage、Questions，以及可选 Answer Key 页码范围。页码均是用户看到的 PDF 页序号，采用从 1 开始且两端包含的范围。
5. 填写书名/资料名、Test 编号、Passage 编号后执行提取。
6. 检查自动识别的标题、正文和题目。可逐题修正题号、题干、题型、选项和答案；无法可靠识别的内容仍保留 `rawText`、来源页与来源块，并标记“需要人工整理”。
7. 如 PDF 中没有可直接提取的答案，可在 Answer Key 文本框粘贴 `1 FALSE`、`2. A` 这一类逐行答案，再按题号应用。无法解析的非空行会保留并提示。
8. 确认导入。重复的文件指纹、页码范围与 Passage 组合会被阻止，不会静默生成副本。
9. 导入完成后可立即练习、返回题库，或继续检查导入结果。

## 当前识别范围

- 已支持并用原创样本覆盖：`TRUE / FALSE / NOT GIVEN`、单项选择。
- 支持基础识别和通用作答：填空、简答。
- `Matching Headings` 和其他无法稳定映射的版式会保留原始题干，以简答输入回退，并显示“待完善题型”。
- `YES / NO / NOT GIVEN` 尚未单独建模；复杂表格、跨栏阅读顺序、多选、流程图、图片题和跨页选项需要人工整理。
- 只处理有文本层的 PDF。扫描版页面会明确提示无可提取文本，本轮不会自动 OCR。

不使用 OCR 是为了保持本轮边界可审计：OCR 会引入较大的本地依赖、识别误差、版面重建和额外的隐私处理面。后续应作为用户显式启用的可选能力单独设计。

## 保存方式

- 浏览器/Vite 开发模式：生成的题包、Session、答案和标记由 repository 接口写入 IndexedDB；不使用 `localStorage`，刷新后可以恢复。
- Tauri 桌面模式：前端把经 Zod 校验的 `IELTSPack` 交给 Rust。Rust 只在用户工作区的 `imports/.install-generated-*` 暂存 `manifest.json` 和 Reading 模块，复用现有原生题包校验与安装链路，用户状态仍进入工作区 SQLite。
- 导入元数据包含文件名、字节数、SHA-256、资料名、Test/Passage、各页码范围、导入时间、提取方式、解析器版本、1-based 页码基准、复核状态和去重键；不保存百度网盘 token，也不以绝对路径作为身份。
