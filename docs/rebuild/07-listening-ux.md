# 07 — Listening UX

## Exam

- 仅允许题目需要的播放控制；禁止转写、答案、精听提示和任意速率/跳转。
- Section/Part、题号、已答/标记状态和剩余时间清晰可见。

## Study

- 波形/进度、播放/暂停、±5 秒、速率、音量和当前时间。
- 当前音频位置按 Session 保存，退出与重启后恢复；切换 Section 不混淆位置。
- 转写按稳定 cue ID 与时间区间存储，可逐句回放、高亮、隐藏关键词形成 cloze。
- 转写缺失或未人工确认时显示真实状态，不自动伪造文本。

## 数据边界

媒体资源属于只读题包；播放位置、循环区间、精听填空和笔记属于用户数据。Exam 与 Study 共享内容身份，但权限由模式决定，不能通过 CSS 隐藏代替数据层约束。
