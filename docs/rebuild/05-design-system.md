# 05 — Design System Direction

目标是 English-first 的安静桌面学习工具：Editorial typography、Apple-like restraint、warm paper surfaces。它不是营销网站，也不依赖玻璃特效制造层级。

## 核心规则

- 主背景使用低饱和暖灰，内容面使用近纸白；暗红仅作重点和危险状态，不覆盖大面积阅读区。
- 阅读正文优先：稳定行宽、1.65–1.8 行高、清晰段间距、可调字号。
- 8px 间距基线，常用圆角 8–12px；阴影只表达浮层和拖拽层级。
- Focus、selected、marked、answered、correct、incorrect 必须同时具有非颜色信号。
- 所有核心流程支持键盘导航、可见焦点、减少动画偏好和高 DPI。
- 1366px 保证完整可用，1920px 不无限拉宽正文；窄屏允许堆叠而不截断操作。

现有暖纸色 token 可作为迁移基础，但需要收敛中英文混排、按钮密度、卡片层级和页面标题体系。
